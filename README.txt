NAVIGATING NEW LIFE REHABILITATION CENTER — WEBSITE

Deploy:
1. Extract this ZIP.
2. Open the folder in Vercel (or import it into a GitHub repository).
3. Create a new Vercel project and deploy as a static site.
4. No build command is required; the entry page is index.html.

Before publishing:
- Confirm all services and facilities with the centre. The service cards currently describe enquiry topics, not confirmed clinical treatments.
- Confirm the full postal address and map pin.
- Confirm business hours, staff credentials, admissions process and any treatment claims.
- Check Google Ads healthcare / addiction-services certification requirements before advertising.
- Replace or add a domain and branded email when available.

WhatsApp:
- All primary WhatsApp buttons and the callback form currently send enquiries to +91 70609 53171.
- The form opens WhatsApp with a prefilled message; it does not store leads on a server.
- To receive enquiries, the visitor must press Send in WhatsApp.
